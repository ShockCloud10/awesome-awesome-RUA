## 快照与使用

records.json 和 metadata/ 保存 remote、commit、提交时间、README SHA256 与许可证信息。仓库提交时间和本次采集时间分别保留，不互相替代；研究发布日期请查看上游条目。

在资料库根目录执行 `git submodule update --init --recursive`，即可取得当前固定版本的全部上游仓库。每个仓库的 README.md 可在对应本地目录打开。

这里只下载和阅读资料；没有安装依赖、运行仓库程序或下载模型权重。第三方仓库保留各自许可证。

主动更新上游时，在该子模块目录切换到所需分支并拉取；然后返回资料库根目录，依次运行 `python3 scripts/index_github.py` 和 `python3 scripts/build_catalog.py`，并将子模块的新提交指针与索引一起提交。
